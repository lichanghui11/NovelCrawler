# 小说爬虫 (Novel Crawler)

> 一个基于 Python 的小说爬虫项目，针对特定网站（m.shuhaige.net）进行全本抓取。
> 本项目旨在通过实际构建过程，学习爬虫的核心逻辑、数据结构设计以及工程化实践。

---

## 1. 项目简介

这是一个**可以运行**的爬虫程序。目前已经实现了从目录发现到正文抓取的完整流程。
它不仅仅是一个脚本，而是采用了模块化的设计，包含了日志记录、断点续爬、数据清洗等基础工程特性。

---

## 2. 已实现功能 (Current Features)

*   **元数据抓取**: 自动提取小说标题、作者、简介、字数、状态等信息，并下载**封面图片**。
*   **目录解析**: 抓取所有章节的链接，生成结构化的目录列表 (`catalog_meta.json`)。
*   **正文抓取**:
    *   **智能翻页**: 自动处理单章内容过长导致的分页（如 `_2.html`），并能准确识别章节结束。
    *   **广告过滤**: 基于关键词和位置自动清洗正文中的广告文本。
    *   **断点续爬**: 自动跳过已下载的章节，防止重复工作。
*   **数据存储**:
    *   采用 **JSON** 格式存储每一章的数据，保留段落结构（`lines` 数组），为后续转 EPUB 做准备。
    *   图片资源保存为二进制文件。
*   **工程化**:
    *   配置了详细的日志系统（同时输出到文件和控制台）。
    *   模块化代码结构。

## 4. 快速开始 (Usage)

### 环境要求
*   Python 3.8+
*   依赖库: `requests`, `lxml`

### 启动爬虫
直接运行根目录下的 `main.py`：

```bash
python main.py
```

程序将按顺序执行：
1.  **获取目录**: 抓取书籍元数据和章节列表。
2.  **抓取正文**: 遍历目录下载每一章内容（支持断点续爬）。

## 5. 待优化计划 (Roadmap)

虽然程序已经可以跑通，但在性能和功能上还有很大的提升空间：

1.  **格式转换 (Exporter)**:
    *   [ ] 编写脚本将分散的 JSON 章节合并并转换为 **EPUB** 电子书格式，包含封面和目录。
2.  **性能优化**:
    *   [ ] 目前是单线程同步抓取，速度较慢。计划引入 `asyncio` + `aiohttp` 或线程池实现**并发抓取**。
3.  **存储升级**:
    *   [ ] 引入 `SQLite` 数据库替代文件系统存储状态，提高管理效率。
4.  **交互体验**:
    *   [ ] 增加实时进度条显示 (tqdm)。
5.  **反爬策略**:
    *   [ ] 优化 User-Agent 随机化。
